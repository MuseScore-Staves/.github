## About MuseScore Studio

MuseScore Studio is a sheet-music program. You enter notes, hear them played back, and print or export a score you wrote. It is for music you are composing or arranging with permission. It is not a library of copyrighted sheet music, and downloading a famous score into the program does not make that score yours.

Playback is a guide so you can hear wrong notes. It is not a studio recording. If you need a finished audio file of your own piece, export audio after the notes are right, and keep the score file as the thing you will edit later.

Start with a single staff and a short phrase. A full orchestra template is harder to read until the entry and playback keys are familiar.

![MuseScore with a short original phrase on one staff](https://musescore.org/sites/musescore.org/files/styles/width_740/public/2024-06/MuseScore%20logo%202024.png?itok=v-eVYjgP)

## How to Use MuseScore Studio

1. Start a new score with the instruments you will actually write for.  
2. Enter a few bars and play them back.  
3. Save the score file before you change the layout.  
4. Fix wrong notes by listening, then save again.  
5. Export a PDF or audio only when those bars are the ones you meant.

---

## Features Included in MuseScore Studio

- Note entry for music you compose or arrange  
- Playback so you can hear the phrase  
- Multiple staves when the piece needs them  
- A saved score file you can reopen and edit  
- PDF export for a part or a full score  
- Audio export of your own playback  
- Layout controls after the notes are correct  
- Undo during the session

## Troubleshooting

- Playback is silent? Select the Windows audio device and check that the staff is not muted.  
- The PDF looks cramped? Fix the layout after the notes are right, and export again.  
- A downloaded score will not justify itself? If you do not have rights to that piece, do not add it. Write your own bars instead.
